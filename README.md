# Remix LINE AI Agent (Control Center & Webhook)

This project integrates the **Remix** framework with the **LINE Messaging API** and **Gemini AI** to create a highly responsive conversational agent. It includes a sleek dashboard UI to monitor logs, credentials status, and configure the AI model in real-time.

> [!NOTE]
> This project was initialized in `C:\Users\pongsakorn.tho\.gemini\antigravity\scratch\Remix-LINE-AI-Agent`. The name was adjusted from `Remix:-LINE-AI-Agent` because Windows does not permit the colon (`:`) character in folder names.

---

## Architecture Overview

1.  **Frontend Dashboard (`/`)**: A modern, glassmorphism dark-mode monitoring dashboard where you can check API connectivity states, customize system prompt instructions, and view simulated webhook callbacks.
2.  **API Webhook Endpoint (`/api/webhook`)**: A server-side POST handler that:
    *   Verifies incoming LINE HMAC-SHA256 signatures for security.
    *   Parses user text messages.
    *   Calls the Gemini AI API (`gemini-1.5-flash`) to generate answers.
    *   Replies back to users instantly using the LINE Reply API.

## Setup Instructions

### 1. Prerequisites (Install Node.js)
Since Node.js is not on your current system PATH, you must install it to run JavaScript packages:
*   Download and install the LTS version from [nodejs.org](https://nodejs.org/).
*   Restart your IDE/Terminal once installed to update your environment paths.

### 2. Configure Environment Variables
Copy `.env.example` to a new file named `.env` in the root of the project:
```bash
cp .env.example .env
```
Fill in the following credentials:
*   `LINE_CHANNEL_ACCESS_TOKEN`: The Access Token generated in the LINE Messaging API channel settings.
*   `LINE_CHANNEL_SECRET`: The Channel Secret from your LINE Developers Console.
*   `GEMINI_API_KEY`: Your Google Gemini API Key from Google AI Studio.

### 3. Run the Project Locally
Open a terminal in the project directory `C:\Users\pongsakorn.tho\.gemini\antigravity\scratch\Remix-LINE-AI-Agent` and run:
```bash
# Install all dependencies
npm install

# Run the development server
npm run dev
```
The dashboard will be active at `http://localhost:3000` (or the port specified in your `.env` file).

## Exposing the Webhook for LINE Testing
LINE requires a public HTTPS URL to send webhook events to your local server.

1.  **Install Ngrok**: Download ngrok from [ngrok.com](https://ngrok.com/).
2.  **Expose Port 3000**: Run the following command:
    ```bash
    ngrok http 3000
    ```
3.  **Configure LINE Developers Console**:
    *   Copy the `https://...` URL generated by ngrok.
    *   Go to your **LINE Messaging API** settings in the LINE Developers Console.
    *   Paste your URL with the webhook path appended: `https://<YOUR_SUBDOMAIN>.ngrok-free.app/api/webhook`.
    *   Enable the **"Use webhook"** toggle.
    *   Click **Verify** to confirm that the server successfully handles callbacks!
